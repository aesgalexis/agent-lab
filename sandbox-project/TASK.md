# Tarea para el agente

Trabaja únicamente en este proyecto.

1. Lee `README.md`, `src/text_stats.py` y `tests/test_text_stats.py`.
2. Corrige la implementación de `word_count` para que cumpla los tests y trate correctamente texto vacío o con espacios repetidos.
3. No modifiques los tests.
4. Ejecuta `python -m unittest discover -s tests -v` hasta que todo pase.
5. Crea `AGENT_RESULT.md` con un resumen breve de los archivos modificados y el comando de test ejecutado.
